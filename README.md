# MarsPizza 🍕🚀

Одностраничный лендинг абсурдной компании **MarsPizza** — первая доставка пиццы на Марс.

Чистый HTML / CSS / JS, без сборки и фреймворков.

## Локальный запуск

Открой `index.html` в браузере или подними простой сервер:

```bash
python3 -m http.server 8080
```

## GitHub Pages

В настройках репозитория: **Settings → Pages → Branch: `main` / root**.  
Сайт будет доступен по адресу вида `https://skrega.github.io/marspizza/`.
